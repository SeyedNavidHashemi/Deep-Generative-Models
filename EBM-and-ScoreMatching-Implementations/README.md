# Energy-Based and Score-Based Generative Models

This project implements two advanced classes of Deep Generative Models: **Energy-Based Models (EBMs)** learned via Contrastive Divergence, and **Score-Based Generative Models (SBMs)**, specifically Noise Conditional Score Networks (NCSN), trained via Denoising Score Matching. The project explores the theoretical foundations of unnormalized probability density modeling and practical sampling techniques using Langevin Dynamics.

## Overview

The project is divided into two main sections:

1.  **Energy-Based Models (EBM):** Implements a Convolutional CNN to map images to scalar energy values. The model is trained to assign low energy to real data (MNIST) and high energy to fake data using **Contrastive Divergence (CD)** .
2.  **Score-Based Models (SBM):** Implements a **Noise Conditional Score Network (NCSN)** to estimate the gradient of the log-probability density (score function). The model employs **Annealed Langevin Dynamics** for high-quality image generation and uses a U-Net architecture with **AdaptiveResBlocks** and **FiLM** layers.

## Part 1: Energy-Based Models (EBM)

### Goal
To learn a probability distribution $p_\theta(x) = \frac{e^{-E_\theta(x)}}{Z(\theta)}$ by learning an energy function $E_\theta(x)$ that assigns lower energy values to more likely configurations of the data.

### Dataset
* **Dataset:** MNIST (Digits 0-9)
* **Preprocessing:** Images are resized to $28 \times 28$ and normalized to $[0, 1]$ .

### Methodology
* **Architecture:** A 5-layer Convolutional Neural Network (CNN) with LeakyReLU activations. The output is a single scalar representing the energy of the input image.
* **Training Algorithm:** **Contrastive Divergence (CD)**.
    * **Positive Phase:** Minimize energy of real training samples.
    * **Negative Phase:** Generate "fake" samples using Langevin Dynamics starting from noise (or a buffer) and maximize their energy.
* **Sampling:** Images are generated by iteratively following the gradient of the energy function:
    $$x_{k+1} = x_k - \frac{\epsilon}{2} \nabla_x E(x_k) + \sqrt{\epsilon} z_k$$

### Key Results
* **Generation:** The model successfully generates recognizable digits from random uniform noise.
* **Stability Test:** Initializing Langevin Dynamics with real images results in minimal distortion, confirming the model has learned to place real data in local energy minima.
* **Denoising:** The model acts as a powerful denoiser, recovering clean digits from images corrupted with Gaussian noise ($\sigma=0.2, 0.4$), though performance degrades at very high noise levels ($\sigma=0.6$) due to mode hopping.

## Part 2: Score-Based Generative Models (NCSN)

### Goal
To learn the score function $\nabla_x \log p(x)$ of the data distribution directly, avoiding the need to compute the intractable partition function $Z(\theta)$. This is achieved using **Denoising Score Matching (DSM)** with multiple noise scales.

### Dataset
* **Dataset:** MNIST (Digits 0-9)
* **Preprocessing:** Images normalized to $[-1, 1]$.
* **Noise Scales:** A geometric sequence of noise levels $\{\sigma_1, \dots, \sigma_{10}\}$ from $\sigma_{begin}=30$ to $\sigma_{end}=0.01$ is used to perturb the data.

### Architecture
* **Model:** **ScoreNet** (based on U-Net).
* **Conditioning:** Uses **AdaptiveResBlock** with **FiLM** (Feature-wise Linear Modulation) layers to inject information about the current noise level $\sigma$ into the network.
* **Gaussian Fourier Projection:** Used to embed the scalar noise level $\sigma$ into high-dimensional vectors.

### Conditional Generation (Class-Conditional)
The model was extended to support **Conditional Generation** by:
1.  Adding a learnable `nn.Embedding` layer for class labels (0-9).
2.  Concatenating class embeddings with noise embeddings in the `AdaptiveResBlock`.
3.  Retraining the model to approximate the conditional score $\nabla_x \log p(x|y)$ .

### Key Results
* **Annealed Langevin Dynamics:** Visualization of the sampling process shows images evolving from pure noise (at high $\sigma$) to coarse shapes, and finally to sharp digits (at low $\sigma$).
* **Unconditional Generation:** High-quality, diverse digit generation.
* **Conditional Generation:** A $10 \times 10$ grid demonstrates the model's ability to generate specific digits (rows 0-9) with high fidelity and consistency.

* Matplotlib
* Google Colab (Recommended for GPU training)

## Usage

### 1. Training EBM
Open `DGM_HW3_EBM.ipynb` and run the cells.
* The notebook trains the EBM on MNIST.
* It visualizes energy values during training and performs denoising experiments.

### 2. Training ScoreNet (NCSN)
Open `DGM_HW3_SBM.ipynb` and run the cells.
* **Unconditional Training:** Trains the base NCSN model using weighted DSM loss.
* **Conditional Training:** Trains the class-conditional model.
* **Sampling:** Generates samples using Annealed Langevin Dynamics and visualizes the denoising trajectory.
