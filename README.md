# Deep Generative Models

This repository contains implementations and experimental studies developed for the **Deep Generative Models (DGM)** course at the **University of Tehran**.

## Contents

The repository covers several major topics in generative modeling:

* **Diffusion & Flow Matching** — DDPM, DDIM, Stable Diffusion, DreamBooth, LoRA, and Flow Matching.
* **EBM & Score Matching** — Energy-Based Models and Score Matching implementations.
* **MAF & CycleGAN** — Masked Autoregressive Flow and CycleGAN implementations.
* **VAE Disentanglement** — Study and experiments on disentangled representations using Variational Autoencoders.

## Topics

The repository explores different families of generative models, including:

* Variational Autoencoders (VAEs)
* Energy-Based Models (EBMs)
* Normalizing Flows
* Generative Adversarial Networks (GANs)
* Diffusion Models
* Score Matching
* Flow Matching
* Representation Disentanglement

Each directory contains the corresponding implementations, experiments, and documentation.
